# 🚀 AutoSched

## 📄 Description
Autosched is a web application designed to enhance academic scheduling by automating exam and presentation coordination, reducing manual errors, and improving efficiency. It offers user-friendly portals for presenters, admins, students, and invigilators, ensuring seamless communication and real-time updates. With features like biometric authentication and AI-generated tests, Autosched provides a secure and innovative solution for academic institutions.The system optimizes resource allocation, minimizes scheduling conflicts, and enhances the overall user experience.
## 💡 Features
- Scheduling Exams
- Scheduling Presentations
- Presentation Summarization
- Report Generation
